### Features

* `fullshot` captures a page that scrolls inside a fixed box. `--scroll-container` names that box (`<sel|@ref>`); with no flag, a document that does not scroll uses the same largest overflow container `scroll` already picks. The receipt and JSON `scrollContainer` name the caller's selector or `@ref`, or the tag when fullshot picked the container. A frame ref such as `@f1:3` is `Kind: usage` before a marker is written; use a main-document `@ref` or a CSS selector. A missing selector is `Kind: selector`; an element that does not scroll is `Kind: usage` ([#746](https://github.com/EndeavorYen/chrome-cdp-ex/issues/746)). A temporary stylesheet hides scrollbars while that box is expanded, and is removed when the capture ends, so the image keeps the viewport width. A style attribute that was absent is removed again instead of being left empty.
