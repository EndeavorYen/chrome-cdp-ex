### Bug Fixes

* `mock` hit counts stay with the rule for as long as the rule exists, including after a daemon restart and after the recent-hit list drops past 50. The recent-hit list itself is still only for the current daemon. Wildcard patterns follow Chrome `MatchPattern` (`*` any length, `?` zero or one character, `\` escapes) against the fragment-free URL: a pattern with `://`, a leading `*`, or a scheme matches that whole URL; a leading `/` matches the path and query; anything else matches the path and query, and a pattern with `.` also matches the host after `://` plus one subdomain label. A pattern that cannot match a browser URL warns when it is added. The HTTP cache is disabled while a mock is active. `cdp help` and the command reference state the rule ([#609](https://github.com/EndeavorYen/chrome-cdp-ex/issues/609)).
