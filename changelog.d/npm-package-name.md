### Docs

* The npm package name is `chrome-cdp-ex`, with a `chrome-cdp-ex` bin beside `chrome-cdp`. `package.json` records the git repository, homepage, bugs URL, and Node `>=22`. Release tarballs are named `chrome-cdp-ex-<version>.tgz`. Install stays a GitHub Release tarball or a git checkout. `pi-chrome-cdp` on npm is the upstream package.
