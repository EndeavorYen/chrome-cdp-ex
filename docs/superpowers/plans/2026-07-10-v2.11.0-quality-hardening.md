# v2.11.0 Quality Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix every evidence-backed v2.10.0 review finding, prove the fixes in a real browser, merge them to `origin/main`, and publish v2.11.0 through GitHub Releases.

**Architecture:** Keep `cdp.mjs` as the command runtime while adding small pure helpers for privacy, bounded output, CLI argument normalization, and campaign verdicts. Extend existing benchmark scripts with distinct profile contracts and a matched CLI route runner instead of creating a second benchmark framework.

**Tech Stack:** Node.js 22 ESM, Chrome DevTools Protocol, Vitest, ESLint, stdio MCP, GitHub Actions/Releases.

## Global Constraints

- Zero runtime dependencies.
- PR base is `origin/main` (`EndeavorYen/chrome-cdp-ex:main`).
- No npm registry publish.
- GitHub Release must include the validated package tarball and checksum.
- Every behavior change follows red-green-refactor.
