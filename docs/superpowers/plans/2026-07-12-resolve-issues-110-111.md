# Resolve Issues #110 and #111

## Goal

Remove false-success results from nested flow/repeat execution and flow wait
aliases while preserving actionable failure transcripts and structured handoff.

## Contract

- A halted `flow` remains inspectable in text or `chrome-cdp-ex.flow.v1`, but
  the daemon boundary returns `ok: false`.
- Default `repeat` fails on the first unsuccessful inner command and preserves
  its complete per-iteration transcript. `--continue` remains the explicit
  override and reports final counts.
- `wait dom stable` and `wait network idle` succeed only when their condition
  is observed. Timeout rejects with condition-specific diagnostics.

## Verification

1. Add failing unit regressions for text/JSON flow handoff, nested flow repeat,
   `--continue`, DOM timeout, and network timeout.
2. Implement the smallest boundary and settle changes.
3. Run the complete test, lint, docs-contract, and live CLI smoke gates.
4. Open a PR fixing #110 and #111, require green GitHub checks and a valid Grok
   Build CLI `pass` with no blocking findings, then merge to `origin/main`.
