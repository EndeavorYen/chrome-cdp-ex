# Issues #115-#119 Reliability Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resolve every open issue in chrome-cdp-ex and publish the verified fixes as a new GitHub release.

**Architecture:** Add small pure reliability classifiers under `skills/chrome-cdp-ex/scripts/lib/`, feed them bounded evidence from the existing daemon, and keep the CLI as the shared implementation behind MCP. Release metadata advances to v2.13.0 after all functional gates pass.

**Tech Stack:** Node.js 22 ESM, Chrome DevTools Protocol, Vitest, ESLint, GitHub Actions.

## Global Constraints

- Do not add runtime dependencies.
- CLI and MCP must return the same bounded findings.
- No screenshot retry loop may run more than once.
- PR target is `EndeavorYen/chrome-cdp-ex:main`.
- Publish through GitHub Releases/tags/assets only; do not publish to npm.
