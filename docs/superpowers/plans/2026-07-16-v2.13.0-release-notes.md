# v2.13.0 Release Notes Rewrite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace commit-oriented v2.13.0 notes with an operator-facing explanation of what changed from v2.12.0, consistently across the repository changelog and published GitHub Release.

**Architecture:** `CHANGELOG.md` is the concise source-of-truth summary; the GitHub Release expands the same five behavioral changes into a Before/Now comparison, scenarios, compatibility notes, validation evidence, and traceability. The release tag and tarball remain unchanged.

**Tech Stack:** Markdown, repository docs-contract checks, GitHub Releases via `gh`.

## Global Constraints

- Explain v2.12.0 → v2.13.0 behavior, not commit activity.
- Preserve factual boundaries for black-frame detection, overlap detection, and indeterminate page health.
- Do not imply npm registry publication; GitHub Releases remain the official distribution surface.
- Keep tag `v2.13.0`, asset `pi-chrome-cdp-2.13.0.tgz`, and SHA-256 `09e05f0683a2dd903d5581251514ae0414d26bdcf7ffe86c11d6da3ea0c55bdf` unchanged.
